# Mega Drive — Genesis Plus GX browser build

RetroRoom's independent Mega Drive program uses the libretro Genesis Plus GX
revision `f27655b592ef43f317272d79883bcaa10d3ac8ad` and Emscripten **4.0.19**.
Build ID: `genesis-plus-gx-f27655b-web-1`. First integration: **2026-11-01**.

## Rebuild from the supplied source kit

Install Python 3 and unmodified Emscripten 4.0.19 (`emsdk install 4.0.19`, then
`emsdk activate 4.0.19`). Extract `genesis-source.tar.gz`. No account, make,
downloaded emulator package, RetroArch, Mesen or DOSBox source is needed.

From the included `retro-room` folder run:

```
python3 scripts/build-genesis.py --source ../genesis-plus-gx --emsdk /path/to/emsdk --jobs 4
python3 scripts/package-genesis-source.py --source ../genesis-plus-gx
```

The package includes full upstream `core` and `libretro` source trees, original
LICENSE/README/HISTORY/Makefile, the actual modified files, native bridge, build
and packaging recipes, frontend source and own demo/tests. Standard compiler
system libraries/toolchain are separately available; runtime notices accompany
the executable. No precompiled emulator object is needed for relinking.

The build recipe makes two idempotent, dated upstream changes:

1. `libretro/libretro.c`: output at 48 kHz, matching RetroRoom's audio pipeline.
2. `core/input_hw/gamepad.c`: snapshot the controller TH handshake, timeout and
   latch data, so replay preserves the 6-button read protocol.

The bridge adds SRAM, the startup overclock delay, 68000 bus refresh/polling
timing and VDP field/HV latch to the normal native snapshot. These are required
for fresh restore and speculative rollback. It zeroes unused snapshot padding.
It uses RGB565 output converted to RGBA, two 6-button ports and MEMFS only.

## Supported behavior and limits

- Mega Drive/Genesis cartridge ROMs only: ordinary big-endian `.md`, `.bin`,
  `.gen` files, up to 8 MiB. No ZIP, interleaved SMD, 32X, Mega-CD, BIOS selection,
  multitap, lightgun or other Sega systems in this first version.
- Solo with local player 2, keyboard/gamepad remapping, fullscreen, solo local
  `.rrstate` download/import, and IPS/BPS via Game patcher.
- Invite-only shared emulation uses the existing input-only protocol, exact
  local ROM matching and rollback. No ROM or savestate is sent to a guest.
  Streaming uses the existing WebRTC host video/audio and guest input mode.
- PAL/NTSC auto region from the ROM. The 68000 CPU ratio supports 100–500%;
  upstream activates it after **100 emulated startup frames**. Video cadence
  stays unchanged; overclocking may break software. Both netplay peers use the
  same setting and build. Z80 remains at its normal speed for Mega Drive.
- Six-button ports are fixed for this release. Games requiring a physical
  3-button pad or special peripherals may be incompatible.
- Tests use original homebrew, including all pad buttons, sound, PAL/NTSC,
  overclock workload, cold restore, SRAM and delayed/reordered rollback.
  This does not establish compatibility with every game or ROM hack.
- Savestates are build/game/CPU specific and may contain emulated game code.
  Nothing is stored automatically after closing the page. Standalone SRAM
  export, battery save auto-persistence and Mega-CD are not offered yet.
